# Foodies Run Club Web App

A one-page Foodies Run Club site with a bold social-run style inspired by the Noe Bad Vibes vibe.

## Features

- Branded hero with logo, strong typography, and CTA buttons.
- Image-heavy collage and expanded gallery starter content.
- Upcoming meetup section with featured image.
- Admin upload form for adding new gallery photos.
- `localStorage` persistence for gallery entries.

## Run locally

Open `index.html` in your browser.
